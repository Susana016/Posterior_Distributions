# Posterior_Distributions

Bayesian inference with Markov chain transition data, including posterior estimation and credible intervals using a Jupyter notebook workflow.

## Project Contents

- `Posterior_Distributions_CLC.ipynb`: Main notebook with data analysis, posterior calculations, and visualizations.

## Requirements

This project uses Python 3.9+ and the following packages:

- numpy
- pandas
- matplotlib
- networkx

Install dependencies with:

```bash
pip install -r requirements.txt
```

## How to Run

1. Create and activate a Python virtual environment (recommended).
2. Install dependencies from `requirements.txt`.
3. Launch Jupyter:

```bash
jupyter notebook
```

4. Open `Posterior_Distributions_CLC.ipynb` and run cells top to bottom.

## Notes

- The notebook includes posterior distribution outputs and a 95% credible interval calculation for transition probabilities.
- If plots do not render, ensure your notebook kernel matches the environment where dependencies were installed.
